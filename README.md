## Descripción

Este sitio reúne mi presentación profesional y una selección de los proyectos que mejor representan mi experiencia práctica. Fue diseñado para ofrecer una lectura rápida y clara tanto a reclutadores como a posibles colaboradores.

## Contenido

- Presentación y objetivo profesional.
- Formación en Licenciatura en Sistemas en la UNGS.
- Proyectos destacados: VoleyInsight, Trading Desk Pro, Cotizaciones y Control de gastos.
- Tecnologías frontend, backend, bases de datos y herramientas.
- Enlaces de contacto, LinkedIn y GitHub.
- Diseño adaptable para computadoras, tablets y teléfonos.
